### 💎 关于这个项目
本项目是 **XBSTACK** 的前端展示层，完美实践了 Astro 5.0 的 Islands 架构。我们追求极致的阅读体验、黑曜石般的视觉质感以及 0 JS 阻塞的性能表现。

### 🏗️ 技术特性
- **0 JS Runtime**: 默认仅加载必要的交互，其余部分均为纯静态 HTML。
- **Ceramic Design**: 独创的陶瓷与水玻璃视觉系统。
- **Global CDN**: 通过 Cloudflare Pages 实现全球边缘加速。
