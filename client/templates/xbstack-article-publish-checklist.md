# XBSTACK 文章发布前检查清单

版本：1.0.0  
更新：2026-07-29

## 选题与库存

- [ ] 已核对站内已发布、已规划和相近主题。
- [ ] 新文章没有重复相同搜索意图、场景或关键词。
- [ ] 已说明文章解决的具体问题和目标读者。
- [ ] 对时效性事实完成官方来源核验。

## 标题与摘要

- [ ] SEO Title 包含明确问题、对象或结果，不只写品牌口号。
- [ ] Meta Description 能说明读者会获得什么。
- [ ] H1 与 SEO Title 可以不同，但搜索承诺一致。
- [ ] Slug 简短、稳定、使用小写英文和连字符。

## 第一屏

- [ ] 前 150—250 字直接回答核心问题。
- [ ] 没有大段背景、空洞趋势或模板化引言。
- [ ] 已明确适用范围、版本、测试环境或数据日期。
- [ ] 页面首屏包含下一步动作或目录入口。

## 正文质量

- [ ] 关键结论有代码、数据、截图、日志、实验或官方来源支撑。
- [ ] 不把计划、推测、Demo 或未上线功能写成已完成能力。
- [ ] 失败条件、限制和不适用场景已说明。
- [ ] 示例中没有真实密钥、Cookie、私人数据或内部地址。
- [ ] 代码能够独立理解，变量、依赖和运行条件完整。

## SEO 与结构

- [ ] 只有一个 H1。
- [ ] H2/H3 层级连续，标题不是关键词堆砌。
- [ ] 图片有描述性 alt，封面尺寸和格式符合站点规则。
- [ ] FAQ 回答真实问题，不重复正文空话。
- [ ] Canonical、hreflang、indexing 状态正确。

## 内链与转化

- [ ] 至少包含一个上级专题入口。
- [ ] 内链使用准确锚文本，不使用“点击这里”。
- [ ] 没有链接到 404、重定向链或错误语言页面。
- [ ] 有对应工具时，CTA 与工具当前真实能力一致。
- [ ] 站外分发链接使用统一 UTM，站内链接不加 UTM。

## 双语与发布

- [ ] 中文与英文的标题、事实、限制、代码和链接保持一致。
- [ ] 英文稿不是机器草稿状态，且通过双语审计。
- [ ] 发布日期、更新时间和版本说明真实。
- [ ] 内容质量、重复内容、封面、双语覆盖和发布门禁全部通过。
- [ ] 发布后已核对 HTTP 状态、Title、Canonical、Sitemap 和核心交互。
