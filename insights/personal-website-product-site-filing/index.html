个人网站需要备案吗？ICP备案、公安备案与子域名怎么核对

个人网站需要备案吗？刚开始建站时，很多人只有一个博客：写文章、放作品、留下联系方式。等到第一个 App 要上线，事情会突然变复杂。产品需要自己的下载入口、隐私政策、账号删除说明、技术支持和 API；博客和产品官网可能使用不同的服务器、接入服务及发布流程；同一个主域名下，还会有 www、products、api 等不同子域名。真正需要回答的是：个人网站应核对哪些备案义务？ICP备案与公安联网备案有什么区别？子域名是否需要单独登记？产品官网取得公安备案号后，主站能不能使用同一个编号？

这些问题没有“一个域名一个备案号”那么简单。先把三件事分开：域名是访问入口，服务器/接入决定服务在哪里运行，ICP备案与公安联网备案分别属于不同管理流程。 同一个人、同一个主域名，不等于所有站点都自动属于同一条网站备案记录。博客与产品官网是否分开部署，应由用户服务、性能、数据安全和维护需求决定，不应以规避备案等法定义务为目的。备案展示必须与真实批准的网站范围一致；不要为了让页脚看起来完整而挂上没有对应关系的备案号。

先核对 ICP、公安备案与实际网站范围

备案判断应从实际提供的服务、服务器与网络接入情况、备案主体和主管部门要求开始。对于使用中国大陆接入资源向公众提供网站服务的情形，通常应先核实并完成适用的工信部 ICP 备案。对于其他接入和部署情形，也应依照现行规则分别确认 ICP、公安联网备案及业务资质要求，不能根据“使用某个境外平台或 CDN”就推定无需申报。两种备案属于不同流程，必要时向接入商和属地主管部门确认具体办理方式。工信部现行《非经营性互联网信息服务备案管理办法》第五条明确了境内通过域名或仅通过 IP 地址访问的网站提供非经营性互联网信息服务的备案范围，因此不能把“没有独立域名”当作当然豁免。阿里云不同场景 FAQ、腾讯云备案场景说明。

再问“子域名要不要备案”。工信部 ICP 备案主要围绕主体、域名、网站及接入信息进行，不是给每一个 www、blog、products 主机名机械发一个独立 ICP 编号。已经备案的主域名下启用子域名，并不意味着每个子域名都必须从零申请一张 ICP 备案证；但当子域名承载实际不同的网站、内容或主体，仍要核对当地管局、当前备案记录和接入商的新增网站/变更要求。公安联网备案不能简单照搬“二级域名一般无需单独 ICP”的结论：产品站的公安备案号是否涵盖主站，最终看已批准的备案网站信息，而不是它们是否同属 xbstack.com。

典型场景ICP 备案判断公安联网备案和展示重点
不同接入环境的个人博客按实际服务器、网络接入、服务范围和备案记录判断 ICP 是否适用，不仅凭机房所在地下结论核实公安联网备案要求与已批准网站范围；不要挂别站编号
中国大陆服务器上的产品官网通常先 ICP 备案、后开放网站按对应已批准网站办理、悬挂备案编号与图标
同一域名下的 www 与 products核对主体/主域名备案、具体网站和接入范围两个真实独立网站应核实公安备案覆盖，不默认共用编号
只有 API，没有公开网页的服务结合境内接入规则核对部分平台指引列有“仅 API”豁免情形，但不应自行推广到全部地区或服务
只是更换 CDN、反向代理或域名解析先核查接入变更、实际源站和服务覆盖检查备案登记网站、服务器和接入信息是否需要变更

这里的说明是帮助技术人员定位申报问题，不是法律意见。具体要求可能随所在省份、备案主体、业务性质、实际服务器与接入商变化。中国大陆网站还可能涉及增值电信业务、前置审批、App 备案等独立事项，不能把“有 ICP 备案号”误解为所有经营活动都获批。

备案材料有哪些？ICP备案与公安联网备案分别怎样申请？

开始之前先做一份真实网站信息表：实际提供的服务、主办者身份、网站域名、负责人、接入服务商、服务器与网络接入情况，以及是否存在需要前置审核的业务。不要把域名注册、ICP 备案、公安联网备案和经营性业务许可当作一个流程。根据工信部公布的现行 《互联网信息服务管理办法》 第八条，非经营性互联网信息服务备案的基本信息包括主办单位及网站负责人、网站网址和服务项目；特定服务还需要依法取得有关主管部门同意文件。不同主体、接入商和地方通信管理局可能要求不同的核验材料，个人主体不应直接照抄企业材料清单。

ICP备案的通常操作顺序是先核对服务和接入情形是否适用备案，再通过实际接入服务商的备案入口提交主体与网站信息、完成相应真实性核验，随后按主管部门审核结果取得或核对备案记录。已有主体新开独立网站时，不要直接重新注册另一个备案主体，应先查询现有登记信息并咨询接入商应走“新增网站”还是“信息变更”。办理入口及主体材料以工信部备案审批服务指南和相关接入服务商当前要求为准。

公安联网备案是另一项独立办理事项。 根据全国互联网安全管理服务平台的现行办事路径，可从 全国互联网安全管理服务平台 登录，在真实主体下进入网站业务、按需要办理新办网站申请，并填写与实际服务一致的网站和负责人信息。公安备案涉及身份及安全责任材料，具体应以平台当次要求为准；不能默认某一份“域名证书、身份证复印件”的旧清单适用于所有个人和企业。收到审核结果后，进入已备案网站详情取得对应网站的备案编号、原始图标和官方 HTML 查询链接。腾讯云的公安联网备案流程指引也说明了开通后的申报与悬挂步骤，但平台及属地主管部门要求优先。

读者任务应准备和核对什么完成后验证什么
第一次申报非经营性 ICP 备案主体与负责人、网站网址、服务项目、真实接入与按要求补充的核验材料管理系统可查到对应网站/主体记录，编号与实际展示一致
已有主体新增产品官网原主体备案、产品站服务内容、真实网站域名和实际接入确认需要新增网站、接入或变更，而非假设原记录自动涵盖
办理公安联网备案已申报的真实网站及负责人、安全责任信息、平台要求的附件公安平台显示审核通过，取得对应站点编号与原始展示代码
后续变更网站信息变更前后的网站网址、服务项目、主体或接入资料主管平台与页面展示保持一致，保留审批/变更回执

备案多久办完？ 不应把一个服务商宣传的“几天”当作普遍承诺。材料准备、接入商真实性核验、通信管理部门或公安部门审核属于不同环节，处理时间因材料、地区与案件情况而变；应查看当次官方受理页面的状态和办理时限。尤其不能把“公安联网备案常见的开通后 30 日内申请要求”误写成“公安机关保证 30 天内批准”，也不能在未审核通过时先悬挂备案号。非经营性备案管理办法和公安备案办事指引适合分别核对流程与节点。

备案号怎么查询？换域名、改服务或换接入后怎样处理？

核对备案号，先到工信部备案管理系统查看 ICP 备案主体、域名和网站登记情况，再到全国互联网安全管理服务平台查询公安备案编号对应的实际网站。查询结果应以当时系统显示为准；仅凭网站页脚写着某个编号、或一个子域名已经挂有编号，都不能认定另一站获得相同登记。若查询页面或相关信息暂时不可用，应保存待核对状态并向接入商或主管部门咨询，不自行猜测覆盖范围。

当网站网址、服务项目、主办者或相关登记信息发生变化，先判断需要 ICP 备案变更、接入备案、另行新增网站，还是公安备案信息变更。《互联网信息服务管理办法》第十一条对变更服务项目、网站网址等事项设有提前办理变更的规定；非经营性备案管理办法也要求履行相应变更程序，不能等到网站已切换、旧备案链接无法使用时才补救。公安备案的变更事项与办理时点应按该平台和属地机关要求处理。此时最有用的操作并不是多挂几个备案号，而是停止显示不符合现有批准记录的信息，并完成真实变更核对。

为什么个人博客和产品官网适合分开？

一个个人博客与一个产品服务站，访问者目的明显不同。博客的任务是解释技术、保留观点、展示长期作品；用户希望找到作者写过什么、实验如何复现、文章何时更新。产品官网的任务是让用户判断一款软件是否适合自己，并及时找到下载、隐私政策、使用条款、账号删除与联系支持入口。把所有内容塞进主站的产品二级目录不一定错，但当部署周期、隐私披露和服务稳定性要求不同，分站能把风险分离，也让产品的法律页面不再依赖博客的内容发布节奏。

分站并不自动意味着 SEO 更好。Google 将站点名称的识别范围定义到域名或子域名层级，但没有“独立子域名排名天然更高”的规则。Google Site Names 文档 强调的是站点识别和结构化信息，不是搜索流量保证。对于独立开发者，选择的核心应是用户任务和运维责任：内容相近、发布节奏一致、团队和数据共享时，主站下的目录可能更简单；当产品拥有单独发布、支持、登录或合规流程时，独立子域名更容易管理。

XBSTACK 的真实情况可以说明这一点。个人内容主站使用 www.xbstack.com，长期积累文章、AI 技术专题和工具；独立产品站位于 products.xbstack.com，承载 Lunest 与 Recalia 的介绍和法律支持页面。2026 年 11 月 4 日，XBSTACK 将独立产品站的公安备案号、查询链接和官方原始图标加入产品站页脚，并通过独立发布脚本部署到不同的服务器发布目录。该次公网检查覆盖22 个产品及法律页面，22/22 检查通过。这只是本站那次发布的网页、图标、Canonical 等静态验收结果，不表示 App 已完成上架，不代表全部法律合规已经自动获得认证。

主域名、www、products、api 分别承担什么任务？

同一个注册域名可以配置多个子域名。比如 www 用于文章与品牌，products 用于产品首页及应用支持，api 用于服务端接口，no-reply 类邮箱域名则负责邮件。不同子域名可以通过 DNS 指向不同接入或 CDN，但“DNS 已解析”不等于“服务已正确隔离”。仍须区分实际源站、TLS 证书、Cookie 作用域、服务器目录、路由表、反向代理、日志、凭据和访问控制。即使两个站点采用不同部署与接入环境，也必须分别核对其可用性、延迟、安全控制与适用监管要求，不能用某个站点的备案信息代替另一站。

技术上，分开部署至少需要四道边界：第一是域名与路由边界，每个站点的导航和 404 都应指向正确站点；第二是发布边界，博客的构建不能顺手覆盖产品站，产品站的独立部署也不能改变主站页面；第三是数据边界，产品表单、登录和 API 权限不应复用博客页面不需要的敏感信息；第四是备案与法律页面边界，备案号对应实际申报的网站，隐私政策与使用条款应对应实际产品服务。

XBSTACK 的一次产品站构建检查，就暴露了这种分离的典型问题：产品站内有文章链接仍然写成根路径，例如 /ai/agent-memory-system/。当同一个 HTML 从 www 迁移到 products 后，根路径就会变成 products.xbstack.com/ai/…，而产品站并没有这条文章路由。修复方法不是给产品站复制整套博客，而是把跨站文章引用明确指回主站的完整 URL，并在自动化构建中检测“独立产品域名上的无效内部链接”。这比泛泛建议“主站与产品站分离”更接近真正的部署成本。

产品官网需要哪些页面？不要只做一个宣传首页

正式产品官网通常至少要让用户能够核对产品用途、当前可用状态、主要平台、帮助与联系方式。如果 App 涉及账号注册、订阅、健康数据或用户上传的私人资料，还需要按真实功能提供相应的隐私政策、使用条款、账号删除与支持页面；不同产品共享一个域名，也不代表可以用一份泛用政策代替差异化数据说明。页面必须跟随实际功能更新，不能把未来计划写成已经上线的承诺。

对于尚未正式上架的产品，首页应该清楚区分“已经可用”“邀请测试”“计划中的能力”。账号删除页应准确说明 App 内入口和官网支持途径，不能展示不可用按钮。英文用户和中文用户进入的帮助页面应该分别使用合适语言，并保持必要法律信息一致。XBSTACK 独立产品站这次检查的是中英文首页、两个产品的介绍页面、隐私/条款/支持/删除账号等共 22 个页面，不代表所有页面未来不再需要持续维护。

不同域名的 SEO、Canonical 和 GA4 怎么做？

第一，给每个公开页面一个稳定、真实可访问的 Canonical。主站文章继续使用 www.xbstack.com 的自指 Canonical，独立产品页使用 products.xbstack.com 的自指 Canonical；不要因为两边同属一个品牌，就把产品站全部指到博客首页。Google 把 Canonical 当作偏好信号而不是绝对命令，内容相同的重复页应优先用 301 或明确的首选地址避免两站互相竞争。Google Canonical 官方说明。

第二，分站维护 Sitemap、robots 与语言对应关系。产品站索引页、博客文章和不适合被搜索的法律或内部页，应根据页面用途分别配置。隐私政策等是否 noindex 不应一刀切；如果产品商店需要公开可访问的隐私 URL，应保证用户和审核方能稳定查看。中英文镜像要使用语言一致的路由和 hreflang，不能把中文帮助页错误指向英文产品介绍。

第三，把跨站链接当成用户导航，而不是“互相刷外链”。博客的产品实战文章可自然链接到产品官网；产品站介绍工程思路可链接回技术文章。参数化的活动链接可用于 GA4 来源归因，但 UTM 不应混入 Canonical。在 GA4 中，应核对跨域或子域名的会话与引荐归因，避免把同一用户跨站访问误报为新增外部流量。无论配置哪种分析工具，都不应把注册邮箱、验证码、API Key、健康数据或导入文档放进普通统计事件。

第四，迁移旧目录时需要 301 和真实 404 回归。假如产品过去使用 /products/lunest/，独立官网现在使用 /lunest/，需要验证重定向属于哪个主机、旧 URL 在主站如何处理，不能只把路径字符串替换而忽略域名。迁移不是删除旧页后重新发一遍；应该检查链接来源、已收录地址、Canonical、Sitemap 和搜索控制台的实际状态。

备案号和公安图标应该放哪里，能不能跨站共用？

ICP备案号应依据真实工信部记录和对应主体、网站与接入情况展示；公安联网备案号及图标则应展示在对应已获批准的网站的规定位置，链接到官方查询页。产品官网已经备案，不代表另一个独立主站拥有同一条公安备案记录。最稳妥的流程是：查明公安备案平台中批准的具体域名、网站名称和主体；属于同一条记录才按该记录的规则展示；不属于就按所在地主管部门指引办理新增或变更，而不是直接复制别站页脚的编号。

2026 年的服务商指引分别讨论了 ICP 备案的接入场景和公安联网备案的办理事项。阿里云 ICP FAQ 可用于核对不同接入场景，腾讯云公安备案常见问题 说明新增网站和信息变更等流程。此类材料仅用于识别需要进一步确认的问题，不能作为迁移服务器以减少备案义务的操作建议。面对同一主域名下的不同服务、跨地区接入或跨境服务，应以实际备案记录、适用规则及属地主管机关意见为准。

XBSTACK 的处理原则是只在已确认的产品官网展示该产品站对应的公安备案信息，不把它复制到主站。产品站发布时保持原图标及官方链接一致，并实际验收页面；未取得对应主站登记前，不冒称主站已经获得公安备案。若主站现有 ICP 页脚展示与实际备案网站范围不一致，也应先核查备案信息，而不是为使所有站点页脚相同而重复复制。

一个人运营两个网站，怎么减少维护成本？

不要一开始就为两个站点建立两套完全不同的工具链。比较容易长期维护的方案是保留同一个源代码仓库或清楚划分的两个项目，但分开环境变量、构建目标、测试清单和部署身份；每个站点在发布前检查自己的首页、导航、Sitemap、Canonical、隐私 URL、跨站链接、API CORS 和实际域名。产品官网应有独立的 Release 目录和回滚方案，避免修改一篇博客就顺便更新用户正在访问的产品法律页面。

最重要的是把“成功”写成可核对的验收结果：构建是否退出 0；有没有把博客文章引用错误地解析到产品站；产品页是否能真实访问；备案图标是否是官方提供的文件；链接是否指向正确登记记录；部署完成后是否仍可回滚到前一个版本。XBSTACK 此次 22/22 的结果正是在这些可检查项目内成立，不能用它推导下载转化率、搜索排名提升或 App 上架审批结果。长期运营时，稳定的边界往往比多开几个子域名更重要。

常见问题

个人网站需要备案吗？ 应依据实际互联网信息服务、主体、网络接入及适用规定判断。中国大陆境内提供非经营性互联网信息服务实行备案制度；具体情形应核对主管部门与接入商要求。

ICP备案和公安联网备案有什么区别？ 两者是不同管理流程：ICP备案涉及互联网信息服务的登记，公安联网备案涉及对应网站的网络安全管理登记；完成其一不代表自动完成另一项。

www、products 等子域名需要单独备案吗？ 不能机械地按每个主机名判断。需要核对已登记的主体、主域名、实际网站及接入信息；独立网站可能涉及新增网站或变更。

个人网站备案需要准备哪些材料？ 基本信息包括主办者与网站负责人、网站网址、服务项目；具体身份核验材料及前置审批要求依真实主体、接入商和官方办理入口而定。

个人网站备案在哪里办理？ ICP备案按适用情形通过实际网络接入服务商和通信管理部门流程办理；公安联网备案使用全国互联网安全管理服务平台及属地受理途径。

网站备案一般需要多久？ 没有适用于全部网站的固定天数。材料核验、接入商审核、主管部门处理以及补正都可能影响时间，应查询实际受理状态与当前公布时限。

网站备案号在哪里查询？ 工信部备案管理系统可以核对 ICP 信息；全国互联网安全管理服务平台可查询对应网站的公安备案记录。只看页脚上的编号不够。

域名、服务项目或接入方式变了，需要更新备案吗？ 应先确认是否属于备案信息变更、接入变更或新增网站；按适用规定和主管平台要求及时办理，不要默认旧记录继续覆盖新情况。

产品官网的公安备案号能复制到博客主站吗？ 不能仅凭相同主域名共用。应先核实公安备案记录覆盖的网站和域名，没有覆盖时不能冒用其他站点编号。

备案通过后图标和编号怎样展示？ 按相关规定和备案平台获取对应网站的备案编号、原始图标与官方查询链接，在指定位置展示并用真实页面验收。

本文是基于 XBSTACK 公开的产品站工程记录和各方官方文档整理的开发与运营实践，不构成针对某个域名的法律审查意见。服务器位置、域名或 CDN 的选择应服从业务和用户需求，不应被当作规避监管的方案。 备案是否办理、需要哪种变更以及经营资质，以实际网站、备案平台记录和主管机关的要求为准。
